# Kivo

Kivo is a Gateway-core + Studio-led platform for monetizing and controlling physical or digital resources with x402, Stellar, Etherfuse, a programmable Gateway runtime, and a TypeScript SDK.

Kivo Gateway is the runtime. Kivo Studio is the AI-agent creation environment. Kivo SDK is the downloadable integration layer. Power Totem is the functional hackathon template. Other templates are roadmap or marketplace candidates.

It combines:

- Kivo Gateway for runtime enforcement near a device, API, automation, worker, proxy, sidecar, or agent tool;
- Kivo Studio for AI-agent-assisted solution building;
- Kivo SDK for TypeScript integration;
- x402 for paid access requirements;
- Stellar for settlement proof;
- Etherfuse for visible anchor/funding context;
- private mainnet billing for validated flows that must remain private.

Power Totem is the only implemented hackathon template today. API Toll, Data Gate, Agent Tool Paywall, Compute Gate, Automation Gate, IoT Device Access, EV Charging, and P2P Energy are roadmap or marketplace candidates until implemented.

---

## Product Shape

Kivo treats every paid thing as a protected resource. A resource can be physical, such as a Raspberry Pi, power totem, kiosk, edge box, or local controller. A resource can also be digital, such as an API, worker, automation, proxy, sidecar, queue consumer, or agent tool.

The core flow is:

```txt
resource -> policy -> x402 requirement -> Stellar proof -> Etherfuse context -> Kivo authorization -> Gateway release -> receipt and health
```

Kivo Gateway enforces the authorization. Kivo Studio helps users design the flow with AI agents. The current Kivo SDK gives developers a TypeScript client for x402 challenge/payment/unlock, Gateway heartbeat, adapters, examples, and tests. Broader resource-policy, authorization, webhook, and pairing helpers are planned after the hackathon MVP.

## Functional Template

Power Totem is the hackathon functional template.

It demonstrates a physical gateway flow:

1. A totem displays a QR checkout.
2. The user pays through an x402 requirement.
3. Kivo validates Stellar settlement proof.
4. Kivo shows Etherfuse anchor/funding context.
5. Kivo issues a short-lived authorization.
6. The physical gateway releases a safe load.
7. Kivo records status, health, receipt, and completion events.

Other templates, including API Toll, Data Gate, Agent Tool Paywall, Compute Gate, Automation Gate, IoT Device Access, EV Charging, and P2P Energy, are roadmap or marketplace candidates rather than hackathon-ready features.

## Templates

<a id="template-power-totem"></a>

### Template Power Totem

Power Totem is the first functional Kivo template. It represents a physical gateway that releases a safe load only after Kivo validates the x402 payment requirement, settlement proof, Etherfuse funding context, and short-lived authorization.

<a id="template-api-toll"></a>

### Template API Toll

API Toll is a roadmap or marketplace candidate for applying the same resource-policy-authorization model to an HTTP route. A protected endpoint returns an x402 requirement, Kivo verifies payment state, and the digital gateway lets the request continue only while the authorization is valid.

<a id="template-agent-tool-paywall"></a>

### Template Agent Tool Paywall

Agent Tool Paywall is a roadmap or marketplace candidate for AI tool calls. An agent requests a paid tool, satisfies the x402 requirement, and receives a scoped authorization for that tool invocation without relying on a standing API key or monthly billing account.
